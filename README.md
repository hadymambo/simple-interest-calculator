# Simple Interest Calculator

A web-based Simple Interest Calculator developed using HTML, CSS, and JavaScript as part of my Full Stack Software Developer learning journey.

## Project Overview

This project provides a simple interface for calculating interest based on a principal amount, annual interest rate, and time period.

The project demonstrates foundational front-end development skills, including HTML structure, CSS styling, JavaScript programming, and user interaction.

## Technologies Used

- HTML5 — Webpage structure
- CSS3 — Styling and layout
- JavaScript — Calculator logic and interactivity

## Simple Interest Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- Principal is the initial amount of money.
- Rate is the annual interest rate expressed as a percentage.
- Time is the duration in years.

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the required values.
4. Use the calculator to calculate simple interest.
